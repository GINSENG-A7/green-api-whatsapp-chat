# **Веб-мессенджер на React с интеграцией GREEN-API**

Тестовое задание на должность Фронтенд разработчик React.

Приложение представляет собой SPA-клиент для обмена текстовыми сообщениями с использованием REST API сервиса GREEN-API.

# **Технологии**

* React 18  
* Vite  
* SCSS (Sass)  
* GREEN-API HTTP REST API (SendMessage, ReceiveNotification, DeleteNotification)

# **Требования перед запуском**

Для локального запуска и проверки работы приложения вам понадобятся:

1. Установленный Node.js (версия 16.x или выше) и npm.  
2. Учетные данные инстанса GREEN-API:  
   * `idInstance`  
   * `apiTokenInstance`

Получить учетные данные можно бесплатно в личном кабинете GREEN-API, создав инстанс и отсканировав QR-код в WhatsApp.

# **Инструкция по локальному запуску**

1. **Клонирование репозитория:**  
   `git clone <https://github.com/GINSENG-A7/green-api-whatsapp-chat.git>`  
   `cd <green-api-whatsapp-chat>`  
2. **Установка зависимостей:**  
   `npm install`  
     
   Если препроцессор Sass не был установлен ранее, установите его дополнительно

:  
`npm install -D sass`

3. **Запуск сервера разработки:**  
   `npm run dev`  
4. **Открытие в браузере:**  
   Перейдите по адресу, который отобразится в терминале (обычно `http://localhost:5173`).

# **Порядок работы с приложением**

1. **Авторизация:** На стартовом экране введите ваши `idInstance` и `apiTokenInstance` из личного кабинета GREEN-API и нажмите **«Войти»**.  
2. **Создание чата:** В боковой панели слева введите номер телефона получателя в международном формате без знака `+` (например, `79991234567`) и нажмите **«Открыть чат»**.  
3. **Отправка сообщений:** Введите текст сообщения в поле внизу и нажмите кнопку отправки.  
4. **Получение сообщений:** Входящие текстовые сообщения подгружаются автоматически раз в 5 секунд с помощью механизмов HTTP-поллинга.
